# 🖐️ دوربین هوشمند تشخیص انگشتان دست و افکت‌های آنی (AI Finger FX Vision)

پروژه وب مدرن و پیشرفته جهت تشخیص بلادرنگ (Real-Time) انگشتان دست با هوش مصنوعی و اعمال آنی افکت‌های سینمایی روی تصویر دوربین.

---

## 🌟 ویژگی‌های پروژه

- **تشخیص هوشمند و دقیق انگشتان (۰ تا ۵ انگشت):**
  - مجهز به الگوریتم سه‌بعدی و هندسی دقیق با پردازش ۲۱ مفصل دست توسط **Google MediaPipe Hands**.
  - کارکرد بدون خطا در تمامی زاویه‌ها (مشت، دست مایل، دست برعکس یا کج).
  - تثبیت فریم و حذف پرش (Debounce & Hysteresis).

- **تغییر آنی افکت دوربین با هر ژست:**
  - **✊ ۰ انگشت (مشت بسته):** ماتریس و خلأ دیجیتال (`Matrix Void`) - باران کدهای سبز دیجیتال، نویز اسکن و رتیکل قفل مشت.
  - **☝️ ۱ انگشت (اشاره):** لیزر سایبرپانک (`Cyberpunk Neon Laser`) - شلیک پرتو لیزر نئونی از نوک انگشت، جرقه‌های پلاسما و HUD تاکتیکال قفل هدف.
  - **✌️ ۲ انگشت (علامت صلح / V):** صاعقه و منشور هولوگرام (`Holo Arc`) - پرش جرقه‌های الکتریکی بین دو انگشت، حلقه‌های انرژی و نور منشوری.
  - **🤟 ۳ انگشت:** آتش شعله‌ور و شراره‌ها (`Inferno Blaze`) - زبانه‌های آتشین، ذرات دود و گدازه و مثلث پلاسمایی بین انگشتان.
  - **🖖 ۴ انگشت:** رترو VHS دهه ۸۰ (`Retro VHS 1984`) - گلیچ آنالوگ، جداسازی رنگی RGB، خطوط اسکن CRT و نشانگر ضبط REC.
  - **🖐️ ۵ انگشت (دست کاملاً باز):** سوپرنوا و گرداب کهکشانی (`Cosmic Supernova`) - چرخش صدها ستاره در مدار کف دست و خطوط کیهانی متصل به انگشتان.

- **امکانات جانبی قدرتمند:**
  - **صداهای سایبرپانک هوشمند:** تولید فرکانس و افکت صوتی اختصاصی برای هر ژست با Web Audio API (بدون فایل صوتی خارجی و بدون تأخیر).
  - **اسکلت نورانی دست:** نمایش/مخفی‌سازی مفاصل و استخوان‌های نئونی دست.
  - **حالت آینه‌ای (Mirror):** برای استفاده راحت مانند آینه در وبکم‌های سلفی.
  - **ثبت عکس با افکت (Snapshot):** با کیفیت بالا و ذخیره خودکار فایل PNG روی سیستم شما.
  - **سوئیچ دستی / خودکار:** امکان تست دستی افکت‌ها با کلیک روی کارت‌ها یا حالت هوشمند خودکار با ژست دست.

## 🚀 نحوه اجرا

پروژه در حال حاضر روی آدرس زیر در حال اجرا است:
```
http://localhost:3000/
```

همچنین در هر زمان می‌توانید با اجرای دستور زیر در ترمینال آن را دوباره اجرا نمایید:
```bash
node server.js
```
یا
```bash
npm start
```
سپس مرورگر خود را در آدرس `http://localhost:3000/` باز کرده و دسترسی دوربین را تأیید فرمایید.
